# GTA Photo

将旅行、街道、建筑、室内或风景照片重构为固定 16:9 横屏的现代 GTA 游戏场景，并搭配经典 PS2《圣安地列斯》布局 HUD。默认提供原图与游戏化效果的上下对照，适用于旅行游戏截图、GTA 滤镜、照片变游戏场景及相关图片修改。
