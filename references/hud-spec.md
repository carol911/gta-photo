# HUD：经典 PS2《圣安地列斯》布局适配

## 依据与边界
布局参考 PS2 实机图（Push Square 2021 年文章中的截图）：
https://www.pushsquare.com/news/2021/08/soapbox_gta_san_andreas_is_still_an_open_world_classic
参考截图：
https://images.pushsquare.com/98e662ecd7e38/gta-san-andreas-ps2-soapbox-4.900x.jpg

实机图可见武器在左、时间在右、红生命条在时间下方、金额横跨下方，无通缉星显示。白护甲条是有护甲状态的适配；不同状态并非所有元素一直出现。装备源图来自用户指定的GTABase页面，详见equipment-assets；保留源图而不是自绘。没有捆绑上述实机截图、原版字体或未获准的第三方风格作品。不承诺整套HUD与PS2实机像素一致。

## 排版（最高优先级）
右上角的紧凑组合：
1. 左列：当前装备透明源图（见equipment-assets），保留其灰白主体、黑色轮廓及自带边框；不另套App方框。新场景生成时槽内只保留背景，源图在最终步骤叠加。
2. 右列上：白色粗黑描边数字时钟，24 小时 HH:MM。
3. 右列中下：白色护甲条（有护甲时），红色生命条；细长黑边，右缘与时间对齐。
4. 两列下方：暗绿色／中绿色粗黑描边金额，横跨组合宽度，类似 $00002350 的八位数值。
5. 默认零通缉：完全不画星星，不能展示一排五颗／六颗灰星当装饰。用户要求通缉时使用最高六星的系统，只激活所需数量，不凭空更改场景为暴力追逐。
6. 空手无弹药数字；无关手机图标、物品栏、时速表不添加；场景交互遵循 interaction-rules.md。

尺度沿用已认可的较大HUD观感，适配16:9画布。以1920×1080为基准：右上组宽约270px、距右约45px、距顶约34px；按s=min(W/1920,H/1080)等比缩放。不得拉伸图标或改变固定左右布局。参考资产里的现代HUD全部忽略。

右上所有元素共用规整矩形网格，但不新增整块外边框。装备源图的线框左缘与绿色金额美元符号的左缘（含描边）左对齐；时钟、生命和护甲共用右缘，金额行位于相同左右界限内。图标位置由实际美元符号左缘决定，不能继续在空槽里水平居中。基准内部左界建议1613px；真实成图以实测为准，传overlay-equipment.py的--align-left。图形自身越框装饰保留在整体组内，不裁图标或移动已认可金额；空间不足先清理正确区域。

左下圆形雷达、黑色轮廓、低饱和地图、白色三角玩家标记、小N。1920×1080基准直径约210px、距左48px、距底65px，同一s等比缩放；不添加GTA V式下方状态条。已认可成图局部编辑时锁定原雷达，不因新尺寸规则重画。

地图内容必须是正上方正交俯视的二维矢量风格：平涂色块、均匀清楚的路网线、简化岸线与地块边界。道路、陆地和水域均无纹理、无照明渐变、无投影、无高度；禁止倾斜/透视/等距地图、卫星照片、缩小的场景截图、立体建筑和三维地形。这里要求的是矢量视觉效果，不宣称最终PNG含真正的矢量图层。雷达仍是屏幕叠层，不受场景辉光、雾和暗角影响。

## 内容变化
- 地图描绘本张照片相应道路／地形：海边有岸线、街道有路网、山地有山路，不能重复套同一海岸地图。它是游戏化示意，绝不称作真实导航或地理测绘。
- 玩家箭头位于可行走区域。允许根据图中视角概括朝向，不把箭头放海里。
- 时间与场景昼夜一致；输入没有明确时间时选一个视觉上合理的虚构游戏时间，不伪称 EXIF 或实拍时间。
- 每张独立新图重新抽取100至999999之间的整数，格式化为美元符号加八位数字；有上一张值时避免重复。连续剧情、同张重试与局部修改锁定金额，购买仅按选中价格递减，不每次重抽。
- 默认生命接近满值；护甲有无可适配，但不能因散步就随机变成濒死状态。
- 保持位置、尺寸、颜色和字体体系固定。内容变化不等于版式随机。

## 装备状态与形状
右上角是当前装备槽，不是随机变形的拳头。出图前按下表明确选装备，并在prompt写具体种类、动作依据；不要每张都无条件填fist。原有动作高于变化：已有角色抱物/点单/打字时通常空手，不能为了换图标改坏动作。只有多个合理候选时才随机或避开上一张装备。已有成图重试锁定装备。

| 场景/动作 | 选装备与行为 |
|---|---|
| 观景、海岸/山体眺望；新增主角驻足且双手可用 | 优先相机，可抬起取景或垂手持相机；保留观看方向，不为拍照转成正面摆拍。原有抱物/明确不用相机时空手 |
| 明确摄影或手持相机 | 相机，动作对应 |
| 花园、花店、送花/约会且手部可用 | 花束；新增主角可持花，已有角色不凭空改掉操作 |
| 普通跑步、骑摩托、抱猫/行李、点单、打字 | 默认拳头；通过scene-rules城市携行/遭遇条件或明确选枪时按武装分支，不能以“正在跑步”否决持枪。骑车/抱物不画额外拿相机的手 |
| 明确持枪、武装角色、选定枪套中的武器或用户指定当前武器 | 明确选手枪/冲锋枪/霰弹枪/步枪的一种并匹配图标；枪不等于开火，装备枪不自动加通缉。只有普通空腰包时不推断武器 |
| 其他和平探索 | 拳头/相机/花束中选择有具体依据的一种，无依据就空手 |

帽子、背包、手机、咖啡、摩托不是原版武器槽候选；不为了图标多样化虚构原生槽位。腰套是人物装备设计，HUD只表示选定装备，不复制整套腰带。

## 可选装备与固定资产
完整42枚图标的ID、英文名、中文释义、源图和校验和见equipment-catalog.json；场景匹配、默认型号及直接叠加步骤见equipment-assets.md。选定具体ID后查看对应资产，不能让图片模型重新理解图形。

武器状态在生成前明确，不能模板默认fist后再希望模型“随机”。无已持握武器的新增原创角色可按用户要求的武装风格选一种当前武器，不需要另加枪战；不得覆盖原人物动作或把和平风景都变成军械展示。抽样只传入场景适用的候选，同图重试锁定状态；完整目录不等于42种都进入旅游随机池。

选定“无人/无主角”时，仅保留基本风格HUD，装备槽可用中性fist，不从路人衣着或持物抽武器，不给NPC塞装备，不启用玩家弹药、准星、枪口闪光或人物交互任务。这里的图标是虚构基础游戏状态，不表示某个路人成了玩家；原人物仍为NPC。明确要求特殊HUD时单独服从其范围，不由HUD反向新增主角。

## 图标执行与局部验收
新图装备槽留空，取得本地图片、实际确认空槽并测得美元左缘后运行overlay-equipment.py --align-left；图形来自固定源图，不能重绘、重上色或描摹。旧错误图标先局部移除并恢复背景，透明合成不会擦除旧图标。

合成后检查装备选择、宽高比、边框、右上间距和其他HUD没有重叠；只改装备时不重抽金额、不重绘雷达、不加载环境参考。固定资产叠加是本技能默认流程，不要求使用者额外完成手工操作。无法合成则说明尚未完成，不以AI重绘冒充固定图标。

## 瞄准状态
准星只在scene-rules选定aiming/firing时出现，携行/观景没有准星。采用小型浅色中心点/细环和少量短刻度，暗色细描边；这是SA风格适配，不声称已核实PS2原版精确准星。定位实际瞄准方向，通常屏幕中心附近，不遮人物后脑，不做巨大现代射击游戏准星、红色命中标记、击杀计数或武器轮盘。瞄准和射击保留相应枪械装备图、弹药字段；开火不自动加通缉星。
