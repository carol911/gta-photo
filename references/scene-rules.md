# 场景、玩家与镜头

## 明确游戏渲染
保留三项地标关系，例如店面轮廓、道路走向与远处山体。允许重构相机和可探索空间，不用像素级保留照片约束抵消游戏化。
- 采用现代AAA开放世界的高精度实时渲染：细密几何、平滑曲面着色、自然复杂轮廓、精细倒角；“建模感”来自统一材质、光照和环境组织，不来自裸露多边形或削平的岩石。圣安地列斯只定义HUD布局，不定义场景年代和画质。
- 材质采用真实尺度的PBR粗糙度、法线和细微磨损；保留皮肤微纹理、织物纹理、墙体和岩石的自然细节。抑制的是摄影噪声和过度锐化，不是几何或贴图质量；不把皮肤磨成塑料。
- 植被保留精细叶簇、分枝、叶片透光和自然轮廓，不能变成多面体树冠；水面使用连贯反射和细波纹，衣服保留大小褶皱、缝线和布料响应，不将布料概括为几个平面。
- 一致的实时光照、接触阴影、环境遮蔽、有材质区分的高光与可见柔和辉光，玩家和环境采用同一渲染强度。
- 以明显的游戏引擎美术为目标，而非追求“无法分辨是否实拍”：建筑、路面、植被和人物统一为高精度游戏资产，使用干净且有尺度的贴图、可辨建模体积、受控而稍风格化的PBR反光、稳定的实时阴影和空气散射。细节充分但不要摄影级随机细纹充满每个平面；不能把原照片背景保留再只处理主角。游戏感也不能靠低模或廉价塑料高光获得。
- 中远景仍可读，避免人像散景、长焦压缩、电影海报调色、卡通描边和单纯加锐化饱和度。
- 保留昼夜天气大类。阴天软阴影，夜晚使用可见灯源，干地不强加雨水，海边不自动变晚霞。

## 人物分支
先在未重构机位的原照片上判定人物角色，再选择玩家，不能先把一个路人放大移到中央再宣称他是原主角。自动识别原主角需同时满足：位于画面中央主体区域、人物占比明显且有清楚的近景存在感、构图/视线/互动显示其是视觉焦点。中央小人影不够；边缘大路人也不自动通过。用视觉语义综合判断，不把“有人”“最近”“最大的人”单独当依据，不凭衣着/性别猜主角。用户明确指定“左边这位就是主角”等可覆盖自动识别门槛。

边缘人物、远处小人物及非焦点人群均保留为NPC。保留其相对位置、距离层次、可见外观、人数和动作，不放大、拉近、移到中央、套主角服装、强塞装备或改成跟随镜头的主人公。允许随全场景统一游戏化材质/光照与有依据的相对运动模糊；“不动路人”不等于保留摄影贴片。没有合格原主角就按无主角分支独立添加原创玩家，不能用路人的脸/身体改造成新增玩家。

| 原图/用户选择 | 行为 |
|---|---|
| 有通过上述门槛的明确原主角，未指定替换 | 保留该主体人数、可见外观、发型、衣物主色与行为；重建为游戏角色，衣物可改为同用途、同轮廓的游戏服装 |
| 多人且有明确中央焦点主体 | 只将合格焦点主体作为玩家，保留其伙伴互动，其余为NPC；多个合格主体且无法确定时问一次，不从边缘/远处强挑 |
| 无合格原主角，无论有无路人 | 原路人保持NPC；默认独立添加一名原创成年女性玩家 |
| 主角男／主角是男／男性主角 | 无合格原主角时添加原创成年男性；有合格原主角时按明确选择替换该玩家造型，保留动作/互动，不多加第二名主角，也不改变路人性别 |
| 主角女／主角是女／女性主角 | 同上，选择原创成年女性玩家；不把原图所有女性或所有人物都改造 |
| 无人／无主角／不要主角／只做场景 | 不新增玩家，也不将任何原人物转换成玩家；保留原人物/路人和空间关系，只统一游戏化场景。无玩家头肩、手臂、主角持装备或人物任务；雷达可示意镜头位置 |
| 保留原人物 | 合格原主角存在时保留；否则保留NPC、不强选主角，是否添加玩家仍按其余明确要求与默认规则 |
| 明确一个人都不要／清除所有路人 | 与“无人”区分，按明确去人编辑处理，不把普通“无人”推断成清空街道 |

不要自动把合格原主角换成女性；默认女性只用于没有合格原主角时的新添玩家。自然语言控制在出图前读取，不需要特殊口令/表单；“主角男/女”控制玩家，不控制NPC。用户选择无人优先于默认女性、武装与近跟随镜头；仅“不要新增人物”也不自动删除原人物。原图有儿童时保留年龄，不擅自成人化；指定男/女不能把儿童改造成成年角色，明确年龄替换意图不清时问一次。无法看清五官时不声称精确身份保留。已有坐姿、点单、摄影等动作优先保留，不能一律改成站立背影。日常穿搭根据气温选择，避免所有场景同一套背心。

## 新增人物的场景动作
仅用于独立添加的原创成年主角；原有主要人物继续保留原动作，用户明确指定动作时优先。先判断面前是否存在连续可通行空间，再选一项，不把原图无人误当成没有动作依据。
- 风景观赏点、悬崖、岸边尽头、面前主要是水面或远景：在合理落脚位置站立观景，身体自然放松，视线朝景观，不跑向断崖或水面。
- 步行路、较窄街道、可通行旷野或平缓草地：沿前方路线跑动，身体略前倾、手臂交替摆动、衣摆/发束有运动响应；不默认静站。未知地形、高灌木或陡坡不能只凭“旷野”强行判可跑。
- 宽阔连续公路、海岸道路或明确可骑行的土路：可默认添加一辆合适的摩托车和一名原创成年骑手，双手握把、沿路行驶；没有充分宽度/地形依据时选跑动，不随机塞摩托。普通城市道路用街车，土路用越野摩托；不新增乘客、不照搬参考人物或车型标识。用户说不加车辆时用跑动。
- 店内/柜台等明确操作场景：按交互安排点单、操作或等待，不启动跑动/骑行分支。没有可辨路线或观景目标时采用站立观察。
普通跑动/骑行属于探索；符合下方遭遇条件时再选武装动作，不由跑步直接推出开火。警察、通缉和任务不自动添加。选定动作后再应用运动模糊，不让“无原始步态”否决合理设计的新增角色动作。

## 有条件的武装变化
这是技能已启用的原创游戏轻剧情分支，不把照片中“有人”当作真实交火证据。无需每次额外询问，先筛选场景，再抽一次并锁定结果。
- 适用：有新增原创成年主角（或用户明确允许改变现有成年主角动作），街道/工业区/开阔路面等有行动空间，前方存在与主角分离的路人NPC，能安排清楚的前后站位。只看到一个远处人影但没有足够空间/动作依据时，不强行选射击。
- 不适用：需要保留的抱物、点单、摄影、坐姿、合影及伙伴互动；儿童主体/儿童参与的场景；用户要求无人、宁静或不新增剧情。保持原主体关系，不为丰富度让所有原人物端枪。
- 没有前方NPC的城市街道/工业区也可有武装携行变化：满足新增成年主角与可行动空间条件时，调用sample-state.py --armed-exploration，只在探索/携行间选，不使用瞄准/射击。普通悬崖观景仍按相机规则，不把所有旅行照片强改成武装。
- 通过筛选时，使用sample-state.py --encounter，或按相同逻辑先明确决定探索/武装携行/瞄准/射击与具体装备。默认相对权重35/30/20/15，只有合适分支参与；不是固定成功率，也不要求一组照片必须凑齐战斗。
- 探索：沿原路线行动，按和平装备规则选；武装携行：手枪低位持握或双手前持，长枪可扛肩/斜背或低位双手持握，枪口不喷火，没有准星。
- 瞄准：默认沿可走路线短暂停步稳定瞄准，此动作覆盖先前探索跑步默认。手枪双手前伸、肩臂有受力，长枪双手持握、枪托抵肩，不把“扛在肩上”当开火姿势。近背侧机位使枪、手及前方瞄准空间可见，主角接近中央，头部不挡准星。aiming显示小型准星，没有枪口火光；射击也默认采用此稳定姿势，用户要求移动射击时再安排对应动态。
- 射击：只有选定firing且能成立明确游戏对峙时才触发。原照片路人保持NPC原位置/外观/动作，不自动武装、改造成敌人或拿其作为射击目标；原主要伙伴、店员或合影同伴同样保留。需要对峙时仅在允许新增剧情且有空间的前提下设计独立原创成年游戏对手，不能冒充原图那位路人；无法合理安排则退回携行/探索。主角保持合适持枪姿势，枪口有明显而集中的黄白橙火光、较丰富短火星及少量淡烟，近处枪/手/衣袖受瞬时亮光；火星从枪口发出，不是远处身体喷火，不添加血迹或伤口特写。后坐用小幅姿态/手臂动态表达，不复制肢体。准星与射线方向一致，HUD装备及弹药匹配。
- 场景不能成立所抽动作时，改选适用携行/探索并说明决策依据，不硬编射击关系；不要凭飞机或枪套加入空袭、警察或通缉。显式用户指定武装/开火剧情优先于本自动分支。

## 相机
以下是工作流构图建议，不是GTA官方镜头参数。默认使用近距离第三人称背后跟随／过肩镜头：相机靠近主角后脑，接近头部高度，轻微侧移，看向人物面前的空间。保留完整后脑、肩背和躯干，下沿收紧到刚过腰带，只露裤腰及极少量上胯布料；不露完整臀部、裤裆、大腿、腿脚或全身。“刚过腰带”是镜头裁切位置，不要求裸露皮肤、降低裤腰或改变身体比例。若衣物遮住腰带，按解剖腰线定位，不强迫掀衣。它提供接近第一视角的代入感，但仍看得见玩家，不自动变成只见双手的真正第一人称。
- 探索：默认约24mm全画幅等效的直线广角视觉；主角仍贴近下方中央略偏侧，两侧环境展开，道路/地砖有清楚的近大远小与透视汇聚，中远景有层次而非长焦压缩。不能仅在提示词写24mm却保留原照片透视。头肩完整，下沿刚过腰带，人物靠近画面中央避免广角边缘拉伸；通过相机距离/机位与透视重建收紧裤子可见范围，不生成后裁掉整图而损坏16:9/HUD，不把后脑放大到遮住半张画面，也不靠把人物缩成远处全身来增加环境。
- 跑动主角：24mm近背后跟随，默认背部中心落在画宽45–55%范围。按daylight-motion参考的视觉占比，以头顶大致在画高35–45%、可见头肩躯干延伸到下沿为起点；肩背约占画宽25–35%，摆臂/包可更宽。下沿刚过腰带的裁切优先于这些近似百分比，裤腰下仅留一小段布料，臀部主体及腿在画外；不能靠改短躯干凑位置。头部和上背核心可辨，摆臂、衣摆、包带及经过环境按lighting-rules应用约两倍增强档动态模糊，不必为看见步幅露出全身。交互/原构图明确要求覆盖此居中默认。
- 摩托骑行：24mm，镜头在骑手后方、骑手尽量居中，适度后退显示上身、握把和部分车身/路面，车轮可在画外；此分支优先于步行腰胯裁切，不做只有后脑而看不出摩托的构图。
- 操作柜台/机器：近距离背侧过肩，选择能看见手、屏幕和操作目标的一侧；保留动作必要范围，可适度后退，但不以全身为目标。不得复制参考图的持枪或瞄准姿势。
- 坐姿休息：保持坐姿，在坐姿头部高度做后侧近跟随，保留视线目标与必要座椅关系，不强迫站起或转背破坏原互动。
- 多人物：保留互动方向，必要时改背侧机位或稍放宽；不为统一背影而让参与者面向错误方向。
- 无人：使用地面人眼高度、约24mm中广角可探索视角，不生成玩家头肩或手臂，不围绕某个路人设置后脑跟随镜头；保留原有路人的相对位置与距离层次。驾驶场景按用户意图采用车辆跟随，不凭空在车外添加玩家。
- 室内默认仍约24mm，优先移机位保持手和操作目标可读；避免鱼眼、桶形弯曲建筑和拉伸肩背。纯航拍/长焦输入可重构合理地面机位；无法推断地面且不允许补全时询问。
- 用户明确要求全身、第一人称、远景或保留相对构图时覆盖默认；不取消新场景16:9，也不假称原样保留的照片机位已改变焦距。

## 16:9构图硬约束
新照片转换的游戏场景固定输出16:9横屏，所有来源比例均适用；最终上下对照图另按output-layout排版，不要求整体16:9。对已认可成图的明确局部修改遵循SKILL.md的编辑范围例外。竖图先识别要保留的主体和地标，再补出两侧道路、室内空间或自然环境；不能把原竖图缩在横画布中，也不能横向拉宽人物。1920×1080、1536×864等都符合比例，不声称模型一定支持某个像素尺寸。保留主体头部和关键动作，近跟随下沿默认刚过腰带、仅露少量上胯布料；这是镜头设计，不是后裁整图来凑比例。脚在画外，人物与地面的空间关系仍须合理；车辆/操作/明确全身等分支保留必要范围。

## 成年角色设计
默认新增原创成年亚洲角色，不直接使用参考人物的脸或身份；已有主要人物继续保留原可见外观，不强改族裔。让角色具有健美、修长而可信的游戏主角比例：肩腰关系清楚、腿部视觉线条利落、头身协调，避免短腿大头、松垮无结构轮廓；不要极端细腰、夸张胸臀、超长腿。保留现有人物的年龄和身体辨识度，适度优化姿态与衣物剪裁；未成年人不使用成年体型与性感穿搭规则。

新增成年女性默认采用美式街头行动造型：白色罗纹棉背心、无品牌鸭舌帽、做旧牛仔或工装裤、有结构的腰带和紧凑腰侧枪套式装备包；可叠加宽松无品牌球衣或敞开短衬衫，避免每次整洁贴身白背心配同一条新裤子。帽下短发/低马尾，有少量松散发束，不默认麻花辫。新增角色允许斜挎一个深色软帆布运动包，宽带横过肩背、包体落在侧后腰，包体有重力塌陷和折痕；跑动时包带拉紧、包体轻微摆动，不能漂浮或融入手臂。斜挎包可与紧凑腰包搭配，但不得堆成满身装备。

服装细节来自受力而非随机纹理：肩带受压、腋下与腰部收拢褶皱、衣摆拉扯、裤腰/口袋/肘部折痕、缝线和少量自然磨损；两侧不完全对称。棉布哑光，粗糙度有差异，不做乳胶般贴皮亮面。角色仍亚洲成年人，美式指服装文化，不改变族裔。不要复制参考球衣号码、品牌、包的独特标识、面巾或脸。腰侧枪套并不自动表示拔枪、开火或通缉。

此默认适用于新加女性，不覆盖现有人物发型/衣服或用户明确造型。冷天在白背心外加适温夹克，骑摩托使用适合骑行的头盔代替鸭舌帽；不为露出腰包拉远已认可机位，允许部分包体在底边附近/画外。

其余造型与情境变化按天气、场合和动作选择，不要把“默认白背心”误当作原图所有人物都必须换装：
- 暖季街头：合身短款上衣/罗纹背心＋有结构的牛仔裤或工装裤，或宽松球衣＋利落短裤；搭一个项链、耳环、帽子或斜挎包重点。
- 城市夜间：短夹克/皮夹克＋合身内搭，深浅材质形成层次；不默认泳装或礼服。
- 男性街头：开襟印花衬衫＋内搭，或合身T恤＋宽松牛仔裤；肩臂有力量感，避免统一健美冠军体型。
