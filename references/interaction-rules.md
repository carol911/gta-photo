# 场景意图与交互状态

先判断实际动作，再添加至多一组主要交互。人物存在不等于正在执行任务。依据不充分时选择自由探索，不编造剧情。

| 可见线索 | 状态与允许UI |
|---|---|
| 普通散步/看风景/合影 | 默认仅基础HUD；可在明确可达的观景点设置一个目的地标记，但不要每张强加 |
| 接近明确店门/入口 | 一个黄色向下入口箭头；对应小地图目标点，落在真实可达门口 |
| 明确前往目的地 | 一个地面红色半透明圆柱检查点，服从地面透视与遮挡；雷达标记一致 |
| 点单/购物/面对机器操作 | 小型列表式选择面板，最多三项短选项、一项高亮、确认/返回提示；内容取自可见商品，无法读取时用简短类别，不捏造真实价格 |
| 坐着休息/持食物 | 基础HUD即可，不凭空出现点单菜单 |
| 正在拍照 | 相机装备与动作一致；保留第三人称，不自动变成第一人称取景器 |
| scene-rules选定武装携行 | 只基础HUD和对应枪械装备；无准星、无枪口效果 |
| scene-rules选定瞄准/射击 | 一枚小型浅色准星，装备/弹药对应；仅射击有枪口火光和短火星，不叠加店铺菜单/光柱/任务卡 |

采用SA经典商店选择交互的思路：矩形深色面板、粗体浅色文字、单行选择高亮；这是适配本照片的菜单，不称像素级原生菜单。默认短英文，用户可指定语言。PS2提示用对应按键符号，不混入Xbox的A/B。没有核实确切按钮对应时用文字“SELECT / BACK”，不要虚构原版键位。

不要自动加入GTA V式武器轮盘、整条蓝色发光导航箭头、悬浮距离菱形、现代任务卡；这些不属于本技能已经核实的PS2基准。用户明确要求混合版本时可适配，但须说明混合风格，不把它称原版SA。

可从“到达观景点、走进店铺、挑选餐点、拍一张照片”中根据场景选一个轻剧情。单张不是完整任务链。菜单不挡脸、手、商品与主要地标；交互状态不同时堆叠任务卡、菜单、光柱和大段字幕。

武装轻剧情依scene-rules的场景筛选与状态抽样，不能只因前方有人就默认正在开火。准星按hud-spec适配，不宣称未核实的原版精确造型；友方互动或不成立对峙时回到携行/探索。
